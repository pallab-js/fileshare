# Contributing to DropBridge

Thank you for your interest in contributing to DropBridge! We appreciate your help in making this local network file-sharing app even better.

## 🚀 How to Contribute

### 1. Report Bugs
If you find a bug, please create an issue on GitHub. Include:
- A clear description of the bug.
- Steps to reproduce it.
- Your operating system and version.

### 2. Feature Requests
Have an idea for a new feature? Open an issue and label it as `enhancement`. Describe the feature and why it would be useful.

### 3. Pull Requests
If you want to contribute code:
1.  **Fork the repository**.
2.  **Create a new branch**: `git checkout -b feature/your-feature-name`.
3.  **Make your changes**.
4.  **Run tests**: Ensure `pnpm check` and `cd src-tauri && cargo check` pass.
5.  **Commit your changes**: `git commit -m "Add feature: description"`.
6.  **Push to your fork**: `git push origin feature/your-feature-name`.
7.  **Open a Pull Request**.

## 🎨 Design Guidelines

DropBridge follows a strict dark-mode-native design system inspired by Supabase. Please refer to [DESIGN.md](DESIGN.md) for detailed typography, color, and component guidelines before making UI changes.

## 🛠️ Tech Stack & Requirements

- **Frontend**: Svelte 5, TypeScript, Tailwind CSS
- **Backend**: Rust (Tauri 2)
- **Environment**: Node.js v18+, Rust v1.75+

## ⚖️ Code of Conduct

Please be respectful and professional in all interactions within the DropBridge community.
